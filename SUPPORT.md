# Support

Use GitHub Issues for reproducible bugs and focused feature requests. General ComfyUI installation, model compatibility, prompting, and GPU questions are better handled by the broader ComfyUI community.

Before requesting help:

1. Install the latest release.
2. Restart ComfyUI and hard-refresh the browser.
3. Read the README troubleshooting table.
4. Check whether the same LoRA works with ComfyUI's built-in loader.
5. Search existing issues.

Include the extension version or commit, ComfyUI version, operating system, installation type, console traceback, reproduction steps, and a sanitized minimal workflow when possible. Never upload checkpoints or LoRA weights.

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
